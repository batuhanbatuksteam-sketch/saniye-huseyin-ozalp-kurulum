# Saniye Hüseyin Özalp Anaokulu — Tablet Uygulaması

Okul öncesi çocuklar için eğitici oyunlar: **Robo Rota** (kodlama), **Labirent Kaşifi**, **Örüntü Treni**,
avatarlı çocuk profilleri ve çıkartma albümü.

## İndir

**[⬇ APK'yı indir (en son sürüm)](https://github.com/batuhanbatuksteam-sketch/saniye-huseyin-ozalp-kurulum/releases/latest/download/SaniyeHuseyinOzalp.apk)**

## Tablete kurulum

1. Tabletin tarayıcısında yukarıdaki bağlantıyı açın, dosya inecek.
2. İndirilen **SaniyeHuseyinOzalp.apk** dosyasına dokunun.
3. "Bilinmeyen kaynaklardan yüklemeye izin ver" uyarısı çıkarsa izin verin (Ayarlar → Güvenlik).
4. **Yükle**'ye dokunun.
5. Uygulama internet varken bulutla eşitlenir; internet yokken de çalışır.

**Türkçe sesli yönerge:** Tablette Türkçe ses yoksa Ayarlar → Sistem → Dil → Metin okuma çıkışı → Türkçe sesi indirin.

**Öğretmen paneli:** Ana ekrandaki kilit simgesine 2 saniye basılı tutun.

Gereksinim: Android 7 veya üstü tablet, yatay ekran.
